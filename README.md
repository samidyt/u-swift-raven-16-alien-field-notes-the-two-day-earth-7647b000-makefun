## The line (130 chars)

> Earth gets four stars: the sunsets are unreal, the snacks are elite, but the dominant species pays rent to live on its own planet.

## Why this line

- **Alien review of Earth:** "the dominant species" and "its own planet" make the visitor's outside view unmistakable; it opens with a four-star verdict.
- **Funny from the alien angle:** the joke is rent itself — an alien cannot fathom paying to live on your own planet.
- **Original:** the rent-on-your-own-planet angle is a specific ownership absurdity, not the first obvious thought about traffic, gravity or weather; the overused "aliens mock smartphones" shape was deliberately avoided.
- **Tight:** 130 characters, a single joke, punch on the last words, nothing to cut.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The program self-checks the gate before writing: 1–200 characters, not only
whitespace, exactly one sentence — and fails loudly instead of handing in a
bad entry. Verified: the line is 130 characters, one sentence, valid UTF-8.
